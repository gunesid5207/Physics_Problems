# Problem 7: Standing Wave Modes

For a string fixed at both ends, each antinode corresponds to one half-wavelength segment.

If the standing wave has $n$ antinodes, then

$$
L = n \frac{\lambda}{2}
$$

Given:

- $L = 80\ \text{cm} = 0.80\ \text{m}$
- Number of antinodes: $n = 4$

So,

$$
0.80 = 4 \cdot \frac{\lambda}{2}
$$

$$
0.80 = 2\lambda
$$

$$
\lambda = 0.40\ \text{m}
$$

## Final Answer

$$
\boxed{\lambda = 0.40\ \text{m}}
$$
